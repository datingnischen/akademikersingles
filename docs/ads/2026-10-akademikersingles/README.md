## Messung und Auslieferung

Bestehende zwei Akademiker-Anzeigen teilen AID `fb-ads`; ihre Umsätze lassen sich nicht je Anzeige trennen. Aktuelle Anzeigengruppe optimiert auf LINK_CLICKS. Änderungen an Motiv und Optimierungsziel deshalb getrennt planen. Ein Wechsel auf Registrierungen setzt ein geprüftes Conversion-Signal voraus.

Budgetvorschlag zur Freigabe: 150 € insgesamt für A+B über 30 Tage (ca. 2,50 €/Variante/Tag). Das niedrige Budget kann nur eine erste Richtung liefern. Bei Möglichkeit zufälligen A/B-Test nutzen; normale Meta-Auslieferung garantiert keine gleichmäßige Verteilung. Bestehende Anzeige als Referenz erhalten, historische Ergebnisse nicht als randomisierte Kontrolle behandeln.
